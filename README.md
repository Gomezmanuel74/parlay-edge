# Parlay Edge

Mobile-first PWA for NFL and NCAA football parlay decision support.

This is analysis software. It never claims a lock. PASS / NO BET is a first-class result. Stake size changes dollars only. It does not change model probability.

## Use it on your phone

Live URL after GitHub Pages is enabled:

https://gomezmanuel74.github.io/parlay-edge/

### Android (Chrome or Samsung Internet)

1. Open the URL above.
2. Tap Install in the app header, or Chrome menu then Add to Home screen / Install app.
3. Open the Parlay Edge icon on your home screen. It runs full screen like an app.

### iPhone

1. Open the URL in Safari (not Chrome).
2. Tap Share, then Add to Home Screen.

## Enable GitHub Pages one time

Repo Settings -> Pages -> Source: GitHub Actions.
Then the workflow on main publishes the app.

## Run locally

```bash
npm install
npm test
npm run dev
```
